## Quy trình 5 bước

```
① TẠO → ② DUYỆT → ③ DỰNG → ④ ĐĂNG → ⑤ BÁN
```

Bước ② là bước duy nhất bắt buộc có ông. Bốn bước còn lại tiến tới tự động hoàn toàn.

## Thước đo

**Thời gian ra một cuốn sách.** Phase nào không giảm được con số này thì không đáng làm.

| | P1 | P2 | P3 | P4 |
|---|---|---|---|---|
| ① Tạo | 1.5h | 1.5h | 1.5h | 1.5h |
| ② Duyệt | 2h | **30ph** | 30ph | 30ph |
| ③ Dựng | 1.5h | 1.5h | **10ph** | 10ph |
| ④ Đăng | 1h | 1h | **5ph** | 5ph |
| **Tổng** | **~6h** | **~4h** | **~2.5h** | **~2.5h** |
